# История изменений

## 1.4.0 — 2026-11-16

- Добавлен **выбор устройства**: можно указать конкретные колонки для системного
  звука или конкретный микрофон. Выбор сохраняется в настройках.
- Микрофон теперь работает и на драйверах, которые не поддерживает основной
  аудиодвижок: при ошибке автоматически включается резервный захват (miniaudio).
- Исправлен повторный запуск: второй экземпляр теперь не «зависает», а через
  локальный сокет просит уже запущенное приложение показать окно.
- Исправлен пропавший трей: если значок не удалось показать или системный трей
  недоступен, окно больше не прячется навсегда — закрытие и сворачивание работают
  как обычно, а если окно всё же спрятано без трея, оно возвращается само.
- Правый клик по шапке окна открывает меню «Свернуть в трей / Выход» — можно
  выйти, даже если значок трея не виден (например, Windows 11 спрятал его
  в переполнение).
- Добавлен локальный лог `%LOCALAPPDATA%\Zamzam\zamzam.log` для диагностики
  проблем с треем, устройствами и запуском.

## 1.3.0 — 2026-11-15

- Добавлена работа в фоне: окно сворачивается и закрывается в системный трей,
  приложение продолжает слушать по **Ctrl + Alt + S**.
- В трее есть меню: открыть окно, начать/остановить прослушивание, история,
  язык и выход. Результат распознавания приходит уведомлением, если окно скрыто.
- Добавлен **английский интерфейс**. Язык переключается кнопкой EN/RU в шапке
  или в меню трея и применяется сразу, без перезапуска. Выбор сохраняется.
- Аккуратное завершение: при выходе закрывается HTTP-сессия Shazam и фоновый
  asyncio-поток.

## 1.2.0 — 2026-11-15

- Распознавание стало надёжнее: приложение слушает 18 секунд и отправляет в Shazam
  фрагменты по 15–18 секунд вместо прежних 10,5.
- Исправлен трек, который не находился на коротком фрагменте
  (Morphy — «Твои поцелуи»).
- Убраны ранние короткие попытки, из-за которых трек с чужим сэмплом мог
  определиться неверно.
- Ручная остановка раньше таймера теперь распознаёт уже записанный фрагмент,
  а не просто закрывает прослушивание.
- Если запрос уже отправлен, приложение дожидается ответа Shazam.
- Тестовые скрипты больше не изменяют настоящую историю приложения.
- Добавлены лицензия, публичная документация и сборка релизов через GitHub Actions.

## 1.1.0

- Переименование EchoTag → Zamzam, новый интерфейс и иконка.
- Единый экран прослушивания и истории.
- Защита от запуска второго экземпляра.
- Ссылки на Spotify, YouTube, Apple Music и Яндекс Музыку.

## 1.0.0

- Первая версия: захват системного звука и микрофона, распознавание через Shazam,
  история, горячая клавиша.
